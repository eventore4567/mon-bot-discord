## Install URL

Utiliser l'URL d'installation générée/configurée dans le Developer Portal pour l'application SentriX. Ne jamais copier l'Application ID d'un autre bot.

Le site SentriX récupère déjà l'URL d'invitation officielle du bot côté application lorsque disponible.

## Vérification obligatoire

Avant l'activation de Discovery :

- le Team Owner doit terminer l'identity/application verification ;
- l'application doit être vérifiée ;
- le menu Discovery doit apparaître dans le Developer Portal ;
- tous les éléments obligatoires de Discovery Status doivent être validés ;
- le bouton Enable Discovery doit devenir disponible.

Une fois activée, Discord indique que l'apparition dans le Directory/App Launcher peut prendre jusqu'à 24 heures.

## IMPORTANT — risque de conformité à corriger

La politique actuelle du Discord App Directory refuse les applications contenant du contenu age-restricted, ce qui inclut le contenu lié au **gambling-adjacent or addictive behavior**.

SentriX possède actuellement des commandes de jeu/économie nommées notamment :

- `gamble`
- `blackjack`
- `slots`

Même si ces commandes utilisent uniquement une monnaie virtuelle, elles peuvent être considérées comme gambling-adjacent. Elles ne doivent pas être cachées dans le dossier de soumission : il faut soit obtenir une confirmation de Discord qu'elles sont acceptables, soit les retirer/désactiver pour la version discoverable avant d'activer Discovery.

## Checklist finale dans le Developer Portal

1. Ouvrir Discord Developer Portal.
2. Sélectionner l'application **SentriX**.
3. Ouvrir **App Verification** et terminer la vérification si nécessaire.
4. Ouvrir **General Information** et vérifier le nom, la PP, la description et au moins 1 tag.
5. Vérifier l'Install URL.
6. Ouvrir **Discovery > Discovery Settings**.
7. Ajouter le serveur support Community.
8. Coller la description et le résumé préparés ci-dessus.
9. Ajouter les médias.
10. Ajouter les liens externes.
11. Ajouter Privacy Policy et Terms of Service.
12. Enregistrer puis utiliser **Preview App Directory**.
13. Ouvrir **Discovery Status**.
14. Corriger chaque élément qui n'est pas vert.
15. Cliquer **Enable Discovery** uniquement quand la conformité du contenu est assurée.

## Une fois publié

Rechercher **SentriX** directement dans l'App Directory et l'App Launcher. Le classement dépend notamment de la pertinence des informations fournies et de la popularité/usage de l'app.
