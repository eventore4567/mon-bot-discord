# SentriX — Plan de lancement 30 jours

Objectif : obtenir des installations réelles, mesurer leur origine et conserver des serveurs actifs.

## KPI principaux

Suivre chaque semaine :

- clics `/go/tiktok` ;
- clics `/go/youtube` ;
- clics `/go/partner` ;
- clics `/go/topgg` / autres annuaires ;
- nombre de serveurs installés ;
- serveurs encore actifs après 7 jours ;
- fonctions les plus utilisées ;
- bugs bloquants remontés par les nouveaux serveurs.

## Semaine 1 — Faire connaître le problème résolu

### Contenu

- 3 vidéos Tickets ;
- 2 vidéos Dashboard / bot tout-en-un ;
- 1 vidéo Modération ;
- 1 vidéo Anti-raid.

### Acquisition

- 5 contacts partenaires personnalisés par jour maximum ;
- viser des serveurs Discord gaming / Roblox avec besoin de tickets ;
- retenter Top.gg ;
- commencer DiscordBotList / Bots.gg / DiscordList lorsque le compte propriétaire permet la soumission.

### Objectif

Trouver les 2 hooks qui génèrent le plus de clics et au moins un serveur testeur actif.

## Semaine 2 — Doubler ce qui fonctionne

- refaire les 2 meilleurs formats avec un nouveau hook ;
- publier un tutoriel court « créer des tickets Discord avec SentriX » ;
- publier une vidéo « 5 Discord bots vs SentriX » ;
- demander du feedback aux premiers serveurs ;
- corriger en priorité les bugs qui empêchent installation, setup, tickets ou dashboard.

## Semaine 3 — Preuve d'utilisation

Si des serveurs utilisent réellement SentriX :

- publier une démo réelle anonymisée avec autorisation ;
- montrer le nombre de fonctions activées, pas de données privées ;
- demander un témoignage court uniquement aux utilisateurs satisfaits ;
- créer une vidéo « ce que SentriX a amélioré depuis son lancement ».

Ne jamais inventer de témoignage, chiffre d'utilisation ou partenariat.

## Semaine 4 — Conversion et rétention

- refaire la meilleure vidéo Tickets ;
- refaire la meilleure vidéo Dashboard ;
- publier un tutoriel complet de 2–5 minutes sur YouTube ;
- améliorer la page `/start` selon les questions les plus fréquentes ;
- contacter les serveurs qui ont installé puis abandonné SentriX pour comprendre pourquoi ;
- préparer le mois suivant uniquement à partir des données réelles.

## Calendrier type hebdomadaire

- Lundi : vidéo Tickets + 5 contacts ciblés.
- Mardi : Dashboard + réponses aux commentaires.
- Mercredi : Modération / sécurité + 5 contacts.
- Jeudi : Tickets variante B + tutoriel.
- Vendredi : IA / communauté + 5 contacts.
- Samedi : comparaison / démo longue.
- Dimanche : analyse des résultats et préparation de la semaine suivante.

## Règle d'optimisation

Après 7 jours, ne pas juger une vidéo uniquement aux vues.

Priorité de décision :

1. installations ;
2. serveurs actifs J+7 ;
3. clics qualifiés ;
4. rétention vidéo ;
5. vues.

Si un format obtient beaucoup de vues mais aucune installation, changer le CTA ou le sujet.

## Seuils de décision simples

- Beaucoup de vues, peu de clics : CTA ou promesse trop faible.
- Beaucoup de clics, peu d'installations : page d'installation / permissions / confiance à améliorer.
- Beaucoup d'installations, peu de serveurs actifs : onboarding ou qualité produit à améliorer.
- Peu de vues mais bonne conversion : garder le sujet et tester de meilleurs hooks.
