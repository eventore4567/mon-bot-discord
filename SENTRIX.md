# SentriX — Bot Discord complet & Dashboard

**SentriX** est un bot Discord tout-en-un avec un **dashboard web complet** pour gérer un serveur sans devoir mémoriser des dizaines de commandes.

SentriX regroupe notamment la **modération**, la **sécurité / AutoMod**, l'anti-spam, l'anti-raid, l'anti-nuke, les **tickets**, les logs, l'IA, les niveaux, l'économie, les mini-jeux, les notifications sociales, les événements, les recrutements staff, les automatisations, les vocaux temporaires, la vérification, les Sticky Roles et les outils de gestion du staff.

## Dashboard SentriX

Le Dashboard SentriX permet aux administrateurs Discord de configurer les fonctions du bot depuis le web : rôles, salons, sécurité, tickets, IA, logs, notifications, économie, niveaux, événements, recrutements, automatisations et panneaux personnalisés.

Les pages publiques du site sont :

- `/` — site officiel SentriX
- `/sentrix` — présentation du bot Discord SentriX
- `/dashboard-sentrix` — présentation du Dashboard SentriX
- `/sitemap.xml` — sitemap pour les moteurs de recherche
- `/robots.txt` — règles d'indexation

Les pages d'administration restent privées et ne sont pas destinées à être indexées.

## Projet

SentriX est développé en Python avec `discord.py` et possède une application web intégrée. Le projet est déployable sur Railway et peut être configuré séparément pour chaque serveur Discord.
